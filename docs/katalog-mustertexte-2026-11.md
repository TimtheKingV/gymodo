## Beinbeuger – sitzend [Beinbeuger]

`leg_curl_seated`, 398 Zeichen

```
Einstellen:
- Sitz und Lehne so einstellen, dass die Knie auf Höhe der Drehachse liegen.
- Unterschenkel auf das untere Polster legen, das obere Polster fixiert die Oberschenkel.

Bewegung:
- Knie beugen und das Polster nach unten und hinten führen.
- Langsam zurück in die fast gestreckte Position.

Achte auf:
- Becken bleibt im Sitz, Hände an den Griffen.
- Auch der Rückweg bleibt kontrolliert.
```

## Wadenheben – stehend [Wadenmaschine]

`calf_raise_standing_machine`, 373 Zeichen

```
Einstellen:
- Schulterpolster so einstellen, dass ein aufrechter Stand möglich ist.
- Vorfüße auf die Plattform setzen, Fersen frei.

Bewegung:
- Fersen langsam so weit wie möglich anheben.
- Kontrolliert bis in die Dehnung absenken.

Achte auf:
- Knie bleiben fast gestreckt, die Bewegung kommt aus den Sprunggelenken.
- Unten ruhig umkehren, Schultern bleiben am Polster.
```

```

Bewegung:

```

## Rudern [Ruderergometer]

`cardio_rower`, 408 Zeichen

```
Einstellen:
- Fußauflagen einstellen und Riemen schließen.
- Griff locker im Obergriff fassen.

Bewegung:
- Erst mit den Beinen drücken, dann den Oberkörper aufrichten, zuletzt den Griff zum unteren Brustkorb ziehen.
- Zurück in umgekehrter Reihenfolge: Arme strecken, vorlehnen, dann Knie beugen.

Achte auf:
- Die Arme ziehen erst, wenn die Beine fast gestreckt sind.
- Der Rückweg ist ruhiger als der Zug.
```

## Klimmzug – Neutralgriff [Klimmzug-/Dip-Gerät]

`assisted_pullup_neutral`, 417 Zeichen

```
Einstellen:
- Unterstützung einstellen: mehr Gewicht macht die Übung leichter.
- Über die Trittstufen einsteigen, parallele Griffe fassen und die Knie auf das Polster setzen.

Bewegung:
- Körper ohne Schwung zu den Griffen hochziehen, Ellenbogen nach unten führen.
- Langsam absenken, bis die Arme lang sind.

Achte auf:
- Knie bleiben ruhig auf dem Polster.
- Zum Aussteigen die Trittstufen nutzen, nicht abspringen.
```
