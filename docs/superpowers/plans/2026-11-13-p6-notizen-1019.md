## Review Focus

1. Wischen in eine Woche ohne Einheiten und ohne Kurse: Streifen zeigt sieben leere Tage, keine Karte darunter, kein Absturz.
2. Gewählter Tag beim Wochenwechsel: die neue Woche fällt auf ihren jüngsten Trainingstag zurück (sonst leer), ein Tag einer anderen Woche bleibt nicht aufgeklappt.

### Task 1: #2 Ein Durchschnittsfeld statt Satzvergleich je Satz

**Files:**
- Modify: `apps/ios-member/FitnessMember/Verlauf/Satzvergleich.swift`
- Modify: `apps/ios-member/FitnessMember/Screens/Home/SessionDetailView.swift` (`blockKarte`, `satzZeile`)
- Test: `apps/ios-member/FitnessMemberTests/SatzvergleichTests.swift`

**Interfaces:**
- Produces: `Satzvergleich.Ergebnis { let deltaKg: Double; let deltaWdh: Double; let gesamt: Trend; let basis: Int }` – das Feld `saetze` und der Typ `Satz` entfallen. `kgText`/`wdhText` bleiben.

Rechnung (meine Entscheidung, im Kommentar festhalten): je Training der Mittelwert aller Kraftsätze (kg und Wdh. getrennt), dann der Mittelwert dieser Trainingsmittel über die bis zu 5 vorherigen Trainings; jedes Training zählt gleich, egal wie viele Sätze. Trend bleibt `gesamt` (Summe kg × Wdh.).

- [ ] **Step 1: Tests umschreiben** – die Tests auf `saetze[...]` ersetzen durch:
  - `vergleichtDenSchnittAllerSaetzeMitDemSchnittDerVorherigen`: vorher a = [(5,8),(7.5,11)], b = [(5,8),(7.5,11)], heute [(7.5,10),(7.5,10)] → `deltaKg == 1.25`, `deltaWdh == 0.5`, `basis == 2`.
  - `derFallAusDerNotizZeigtNullKg`: vorher [(12,10),(12,8),(12,8)], heute [(12,15),(12,12),(12,9)] → `deltaKg == 0`, `kgText(deltaKg) == "±0 kg"`, `wdhText(deltaWdh) == "+3,3 Wdh."`.
  - `andereSatzzahlHeuteRechnetOhneIndexfehler`: vorher [(10,10),(10,10),(10,10)], heute 4 × (10,10) → `deltaKg == 0`, `deltaWdh == 0`, `gesamt == .hoch`.
  - `jedesTrainingZaehltGleich`: vorher a = [(10,10)], b = [(20,10),(20,10),(20,10)], heute [(15,10)] → `deltaKg == 0`.
  - Die übrigen Tests (höchstens fünf, nil-Fälle, Pfeil folgt Volumen über `gesamt`, Texte) an das neue `Ergebnis` anpassen.
- [ ] **Step 2: Rot prüfen** – Suite `SatzvergleichTests`; erwartet: Compilerfehler `deltaKg`.
- [ ] **Step 3: `Satzvergleich.fuer` umbauen** – gibt das neue `Ergebnis` zurück; Kopfkommentar auf die neue Regel (Testnotiz 19.10., #2).
- [ ] **Step 4: View** – `satzZeile` ohne Vergleichsparameter und ohne rechten Teil (Label ohne „gegenüber dem Schnitt“). In `blockKarte` unter den Sätzen eine Zeile: links „Ø je Satz“ (`textFaint`, 12 pt), rechts Trendsymbol (`gesamt`, 12) und `"\(kgText) · \(wdhText)"` (12 pt semibold monospacedDigit, `textMuted`), VoiceOver „Im Schnitt je Satz … und … gegenüber deinen letzten N Trainings“. Fußnote bleibt.
- [ ] **Step 5: Grün prüfen** – Suite `SatzvergleichTests` grün, Build ohne Fehler.
- [ ] **Step 6: Commit** `fix(ios): Trainingsdetail vergleicht den Schnitt der Übung statt jeden Satz`
